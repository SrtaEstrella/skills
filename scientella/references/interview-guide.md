# 冷启动采访指南

> 本文件在 Skill 首次启动且检测到 `.scientella/config.md` 不存在时读取。

## 采访流程

向用户展示以下选择题（仅此一次，后续不再询问）：

```
在开始之前，需要确认几项配置：

① 这是 Obsidian 知识库吗？
   [是，使用 Obsidian 语法（默认）] 卡片文件使用 wikilink、Obsidian tag（如 `#计算机科学`、`#机器学习`、`#概念`、`#通用`）
   [否，使用纯 Markdown] 卡片使用标准 Markdown 链接语法，tag 使用 YAML frontmatter 列表

② 卡片覆盖范围：
   [完整提取（默认）] 提取所有核心术语、关键论断、新颖方法
   [仅核心概念] 跳过高频术语和常识，只输出材料独有的核心概念

③ 输出格式：
   [标准卡片（默认）] 每个概念生成一个独立的 .md 文件
   [含记忆卡片] 在标准卡片基础上，额外生成一个 Anki 制表符分隔导入文件

④ 工作方式：
   [沉浸式（默认）] 产出内容将直接影响您的知识库
   [干净空间] Agent 写操作仅在独立工作空间 `agent-ws` 进行，您的知识库是只读的，产物后续由您自行迁移

⑤ Vault 路径：
   [即当前 Agent 工作空间路径（默认）]
   [自行指定的其他路径]
```

## 配置写入

采访完成后，将答案写入 `.scientella/config.md`：

```markdown
# Scribella 配置

## 语法模式
- [Obsidian / 纯 Markdown]

## 卡片覆盖范围
- [完整提取 / 仅核心概念]

## 输出格式
- [标准卡片 / 含记忆卡片]

## 工作方式
- [沉浸式 / 干净空间]

## Vault 路径
- XXX
```

## 后续操作

如果用户回答了「Obsidian」且提供了 vault 路径，立刻扫描该路径下所有 `.md` 文件的文件名（去扩展名），形成「可用 wikilink 目标清单」。后续生成卡片时，仅对清单中存在的概念使用 `[[wikilink]]`（参见准则 3.4）。
