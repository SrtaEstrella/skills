# Anki 制表符分隔导入指南

> 本文件仅在用户配置为「含记忆卡片」时由 Skill 读取。
> 定义了从知识卡片生成 Anki 兼容导入文件的格式和流程。

## 输出文件

全部概念卡片生成完毕后，额外输出一个文件 `scientella-anki-import.txt`，存放于知识库根目录。

## 文件格式

Anki 标准制表符分隔格式（UTF-8 编码），每行为一张卡片，格式为 `正面\t背面`：

```
什么是[概念名称]？    [概念的核心定义，1-2句话]
[概念名称]与[易混概念]的主要区别是什么？    [区别说明]
```

- 正面和背面之间用 Tab 字符（`\t`）分隔
- 每张概念卡片至少生成 1 对问答
- 如果同一概念有多个可能的易混概念，可以生成多行

## 导入步骤

1. 打开 Anki
2. 文件 → 导入
3. 选择 `scientella-anki-import.txt`
4. 分隔符选「制表符」
5. 勾选「允许字段中使用 HTML」
6. 选择目标牌组，点击导入

## 注意事项

- 此文件不在各概念 `.md` 中体现，而是一个独立文件
- 确保文件编码为 UTF-8
- 如果正面或背面内容包含制表符，需要用空格替代
