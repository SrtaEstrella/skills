# 卡片格式参考

> 本文件由 Skill 在生成卡片时按需加载。定义了两类卡片的标准输出格式。请注意：这只是一个示例，不能穷举所有情况，请务必充分理解 §3 各项规则。

```yaml
- **定义**：**词向量**技术将每个词映射到一个**低维实数向量空间**中，映射过程称为**词嵌入 (Word Embedding)**。
- **核心思想**：
	- 一个词的意义由其**上下文**决定，出现在相似上下文中的词，具有相似的意义。
	- 这一原则被称为**分布假说 (Distributional Hypothesis)**。
- **词向量空间的特性**：
	- **语义相似性**：意义相近的词，其向量在空间中的**余弦相似度**较近。例如，“国王”和“君主”的向量很接近。
	- **语义关系**：词与词之间特定的语义或语法关系，可以表现为向量空间中的**平移关系**。
		- **最著名的例子**：$\vec{king} - \vec{man} + \vec{woman} \approx \vec{queen}$
- **主要方法**：
	- **Word2Vec**：通过**神经网络模型**在大规模无标注语料上训练。
		- **关键超参数**：
			- `embedding_dim`：向量维度，典型取值为 100–300；
			- `window_size`：上下文窗口半径，典型取值为 5。
		- **两种模型**：
			- **Skip-gram**：用中心词预测上下文窗口内的词，擅长低频词；
			- **CBOW**：用上下文词预测中心词，训练速度更快。
	- **GloVe**：基于全局**词-词共现矩阵**，结合了**矩阵分解**和上下文窗口方法的优点，直接优化**共现概率的比值**。
- **训练步骤**：以Word2Vec的Skip-gram负采样为例：
	1. **构建数据集**：从文本中用滑动窗口生成(中心词, 上下文词)正样本，并对每个正样本采样k个负样本词。
	2. **初始化**：为每个词初始化两个向量：中心词向量v和上下文向量u（或输入/输出向量）。
	3. **前向计算**：用中心词的向量v_c与上下文词的向量u_o及负样本向量做点积，通过sigmoid得到概率。
	4. **损失函数**：最大化正样本概率并最小化负样本概率，即二元交叉熵损失。
	5. **梯度更新**：计算梯度并更新v_c、u_o和负样本的u向量（通常使用随机梯度下降）。
	6. **迭代**：对语料所有词窗多轮训练，最终得到词向量（通常取中心词向量v作为最终词嵌入）。
- **在语言研究中的应用**：
	- 词向量可以替代或补充[[TF-IDF]]等传统特征，作为下游任务（如**文本分类**、**情感分析**）的输入特征，提供**语义信息**。
	- 通过计算词向量的[[聚类 (Clustering)]]，自动发现语义相近的词群，用于探索**语义场 (Semantic Field)**。
	- 训练不同历史时期的词向量，通过**向量位置变化**研究词义变化。
- **优点与局限**：
	- **优点**：稠密低维，计算高效；蕴含丰富的语义和语法知识；支持语义运算。
	- **局限**：
		- **一词多义问题**：一个词只有一个向量，无法区分不同含义。
		- **静态性**：训练好后向量固定，无法根据上下文动态调整。
```
